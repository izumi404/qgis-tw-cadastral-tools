# 高雄建物資料助手 · QGIS Plugin v2.0

選取一個範圍 polygon，再選擇要輸出 **Polygon（土地＋建物資料）**，還是 **Point（只有建物定位點）**。外掛自動找相交地段與地政事務所，不需要手動輸入 `EE＋0335`。

目前只支援高雄市；支援 QGIS 3.44–3.x，已於 QGIS 3.44.7 測試。非政府官方外掛，無需額外安裝 Python 套件。

## 版本功能：v1 做了甚麼？v2 新增了甚麼？

### v1.0 — 範圍內建物資料，輸出 Point

選取一個範圍 polygon，自動辨認相交地段與地政事務所，下載範圍內的**建物登記定位點**。

- 提供建號、建物完成日期、地址、樓層數、構造、面積及座標。
- 可額外查詢主要用途、各層及附屬建物面積；亦可替既有建物點補齊資料。
- 支援快取、取消、續跑，以及缺漏和失敗紀錄。

v1 的 polygon 用作查詢範圍；結果是 Point，尚未輸出宗地界線、土地資料或公告現值／地價。

### v2.0 — 新增 Polygon，土地與建物一起查

保留 v1 的 Point 功能，新增「輸出類型」選單，讓使用者選擇 **Point（只有建物）** 或 **Polygon（土地＋建物）**。

- 直接取得逐地號宗地向量，可裁切至範圍或保留完整宗地；同一地號的多片圖形一併保留。
- 加入土地地段、地號、面積、**公告現值及公告地價**；缺值和來源未提供的公告年度留空。
- 按來源土地地段＋地號連結建號，保留一地多建號、完成日期摘要、逐筆建物資料及建號明細表。
- 新增宗地覆蓋／重疊統計、未對應建號紀錄，以及兩種輸出模式的測試。

Point 仍只提供建物資料；額外的主要用途與各層／附屬面積查詢仍限 Point 模式。完整版本紀錄見 [CHANGELOG.md](CHANGELOG.md)。

## 安裝 v2.0

1. 下載 [v2.0.0 安裝 ZIP](dist/kaohsiung_buildings_plugin-2.0.0.zip)，GitHub 檔案頁可按 **Download raw file**。
2. QGIS → **Plugins → Manage and Install Plugins → Install from ZIP**。
3. 選擇 ZIP，安裝並啟用「高雄建物資料助手」。更新後若仍顯示舊選單，重啟 QGIS。

安裝 ZIP 不用解壓。GitHub **Code → Download ZIP** 是整個專案原始碼，不能當作外掛安裝包。

## 使用方式

1. 載入有正確座標系統的 SHP 或其他範圍多邊形圖層。
2. 選取所需 polygon，保持該圖層為目前圖層。
3. 開啟 **Plugins → 高雄建物資料助手 → 1. 依選取範圍取得土地／建物資料**。
4. 在「輸出類型」選 **Point** 或 **Polygon**，設定快取資料夾及主要輸出，建議使用 `.gpkg`。
5. Polygon 模式若需要可直接開啟的逐筆建號表，指定「Polygon：對應建號明細表」的另一個 `.gpkg` 輸出位置。未指定時仍會建立暫存表；主要宗地圖層也保留逐筆建物 JSON。
6. 按 **Run**，完成後開啟主要輸出屬性表查看資料。

有選取圖徵時只處理選取範圍；沒有選取時處理整個圖層。可選多個 polygon，跨地段會查詢多組代碼。範圍在本機計算，完整 SHP 不會上傳；向網站傳送的是行政區、地段、地號或建號等查詢代碼。

## 兩種輸出模式

| 模式 | 圖形與篩選方式 | 附帶資料 |
| --- | --- | --- |
| **Polygon：土地＋建物資料** | 直接取得圖台逐地號宗地向量；保留與範圍有面積交集的宗地，預設裁切至範圍 | 地段、地號、面積、公告現值、公告地價、對應建號數量／清單、完成日期摘要及逐筆建物資料 |
| **Point：只有建物定位點** | 以來源 x97／y97 建立定位點，只保留點位在範圍內的建號 | 建號、地段、完成日期、地址、樓層、構造、面積、座標、事務所；不加入土地／地價資料 |

預設為 Point，保留 1.x 的使用行為。兩種模式的選取範圍都必須是多邊形；選單控制的是**輸出圖形**。

### Polygon 土地＋建物

- 使用 `GETLIST / ITEM=land / hasGeometry=true` 的 WKT 向量，不做影像轉面或 smooth，也不使用整米取整的單筆 `SERVICE=LAND`。
- 同一未截斷回應中，一個地號若分多片圖形且土地屬性一致，會合併保留所有圖形，記錄 `source_parts`；屬性衝突則停止核對。
- 預設裁切至所選範圍；取消「Polygon：裁切至選取範圍」可保留完整宗地。裁切線不等於原宗地界。
- 建物用來源 `aa48（土地地段）＋aa49（土地地號）` 精確對應土地，**不靠定位點是否落在宗地內猜測**。
- 一地多建號全部保留。每幅地一筆，建號明細表每個對應建號一筆，以 `parcel_key` 連接。
- 主圖層的 `buildings_json` 保存該地所有已對應建號及基本資料；明細表更適合在 QGIS 篩選和閱讀。不要只保留第一個建號。
- 同一地號不同建號可以有不同完成日期；摘要只取有效日期的最早／最遲日期，不代表整幅土地有單一建築年份。
- 建物定位點可能在宗地或選取範圍外；只要來源地號對應已選宗地便保留，並以明細欄位標記。

| 土地欄位 | 意義 |
| --- | --- |
| `parcel_key` | 土地事務所｜地段｜8位地號 |
| `section`／`land_no`／`display_no` | 地段代碼／原始地號／易讀地號，保留前置零 |
| `reg_area_m2` | 來源登記面積，不因裁切改寫 |
| `geom_area_m2`／`inside_area_m2` | 完整宗地／範圍內交集的平面面積 |
| `ann_value`／`ann_price` | **公告現值／公告地價**，新臺幣元／平方公尺；沒有乘以面積 |
| `value_raw`／`price_raw` | 原始地價文字；缺漏保留 NULL，真正的 0 仍保留 0 |
| `value_year`／`price_year` | 公告年度；目前接口未提供，留空，不以執行年份代入 |
| `build_count`／`build_refs` | 對應建號數量／建物地段:建號清單；不等於實體建築棟數 |
| `finish_dates`／`finish_min`／`finish_max` | 不重複西元完成日期清單／最早／最遲有效日期 |
| `date_unknown` | 完成日期缺漏或無效的建號筆數 |
| `buildings_json` | 每個對應建號的完整基本欄位清單 |
| `build_status` | 是否找到對應建號；未找到不代表沒有建物 |
| `repaired` | 1 表示來源無效幾何經有效性修復；0 表示未修復 |

公告現值來自 `aa16`，公告地價來自 `aa17`。單位參考[高雄市地政局統計表](https://landp.kcg.gov.tw/CP/2559/)。查詢時間和公告年度不是同一概念。

建號明細包括 `building_key`、`parcel_key`、`office`、`section`、`build_no`、`land_section`、`land_no`、`date_roc`、`finish_date`、`date_state`、`address`、`floors`、`main_floor`、`structure`、`area_m2`、`x97`、`y97`、`point_on_land`、`point_in_range`、`source_url`。位置核對欄為 1=在內、0=在外、NULL=無法定位。

### Point 建物定位點

只輸出範圍內建物資料，不下載宗地向量或土地地價。定位點不是建物輪廓；同棟不同登記單位可能共用座標。

Point 模式可勾「完整資料」，再逐建號取得內政部主要用途及各層／附屬面積，另外指定樓層面積表位置。每項面積一列，以 `building_key` 對應，不應直接加總所有項目當作總面積。Polygon 模式已含來源建物基本資料，但不支援此額外勾選；誤選時會提示取消，不會忽略設定。

已有建物點圖層，可使用 **2. 補齊建物資料與樓層面積**。指定 `section` 和 `build_no`，有 `office` 欄時自動採用；沒有時須提供正確備用事務所代碼。`EE` 只適用楠梓地政事務所。原有位置與欄位會保留，失敗亦保留紀錄。

## 速度、快取及取消

- 網站單次清單上限 1,000 筆，外掛以地號／建號的包含字串搜尋遞迴拆查；完整識別碼仍達上限時停止，不會誤報完整。
- 每次網路請求至少間隔 1 秒；401、403、429 會停止。正在等待的請求須等回應或超時才能取消。
- Polygon 會取得候選地段的宗地及建號清單，因此通常比純 Point 多工序。完整內政部資料逐建號查詢，數萬筆可能需要數小時。
- 相同快取資料夾可續跑；需要更新資料請使用新的空快取資料夾。快取資料可能來自不同查詢日期。
- 取消或失敗後輸出可能不完整；重跑請用新輸出檔案，檢查報告 `finished` 及錯誤紀錄。
- 建議 GeoPackage；SHP 容易截斷欄位名稱、長建號清單及 JSON。

| 快取資料夾報告 | 內容 |
| --- | --- |
| `polygon_report.json` | Polygon 地段進度、宗地／建號數量、價格缺漏、幾何覆蓋、缺口與重疊指標 |
| `polygon_unmatched_buildings.json` | 點在範圍內但未對應宗地，或沒有有效座標的候選建號；不會配到鄰近地號 |
| `report.json`／`unlocated.json` | Point 模式進度及無法定位建號 |
| `detail_report.json` | 額外內政部資料查詢結果 |

## 資料來源與限制

來源：[高雄地籍圖資服務網](https://gisdawh.kcg.gov.tw/landeasy/)、[內政部地籍圖資網路便民服務系統](https://easymap.moi.gov.tw/Z10Web/Normal)。

候選地段採範圍外擴 100 米，缺界線的候選地段亦查詢；最終按原範圍篩選。錯置位置、缺幾何、未登記建物或來源未提供資料可能造成遺漏。來源每筆建號只提供一組土地地段／地號，不代表已取得完整法定建物坐落地號清冊。無對應建號不能等同「空地」。

來源宗地可能有缺口、重疊或更新時差，工具不會擅自補界、裁掉重疊或移動建物點。幾何覆蓋率不代表官方清單完整或實地精度。Polygon 的缺口與重疊指標記於報告，v2.0 外掛不額外輸出診斷面圖層。

## 開發與測試

```sh
python3 scripts/build_plugin.py
```

打包會讀取 `metadata.txt`，產生 `dist/kaohsiung_buildings_plugin-2.0.0.zip`，只收錄外掛所需檔案，不包含個人路徑、宗地資料或快取。

在可匯入 QGIS 的 Python 環境執行離線測試：

```sh
QT_QPA_PLATFORM=offscreen python3 tests/test_qgis_integration.py
QT_QPA_PLATFORM=offscreen python3 tests/test_qgis_v2.py
```

測試涵蓋原有 Point／完整資料工具、選取範圍、Polygon 裁切與完整宗地、Point 不含土地資料、1,000 筆上限拆查、一對多建號、精確地號關聯、價格缺漏與零值、公告年度留空、日期及取消。測試不連線，不能驗證網站即時狀態或官方資料完整性。

## 使用前請自行核對

**請使用者自行 check 資料同位置啱唔啱。** 請抽查事務所、地段、地號、建號、建物完成日期、面積、公告現值／地價、公告年度及位置，並檢查範圍、缺漏、重疊和失敗紀錄。

工具不保證資料正確、完整或最新，亦不代表人工或官方核證。正式使用前應另行核實，並記錄來源與查詢日期。
