# 高雄建物資料助手 · QGIS Plugin

在 QGIS 選取一個多邊形，自動查詢相交地段及地政事務所，再取得範圍內的建物登記定位點與完成日期。可選擇進一步取得主要用途、各層及附屬建物面積。

**目前只支援高雄市，已於 QGIS 3.44.7 測試。** 本專案是自訂工具，非政府官方外掛；無需額外安裝 Python 套件。

## 安裝

1. 下載 [安裝 ZIP](dist/kaohsiung_buildings_plugin-1.0.0.zip)。在 GitHub 檔案頁按 **Download raw file**。
2. QGIS → **Plugins → Manage and Install Plugins → Install from ZIP**。
3. 選擇 `kaohsiung_buildings_plugin-1.0.0.zip`，安裝並啟用「高雄建物資料助手」。

安裝 ZIP 不用解壓。GitHub 的 **Code → Download ZIP** 是整個專案原始碼，不能直接當作 QGIS 外掛安裝包。

## 使用方式

1. 載入有正確座標系統的 SHP 或其他多邊形圖層。
2. 用選取工具選取所需 polygon，並保持該圖層為目前圖層。
3. 開啟 **Plugins → 高雄建物資料助手 → 1. 依選取範圍取得建物資料**。
4. 選擇快取資料夾，指定輸出 `.gpkg`，按 **Run**。
5. 如需主要用途及各層／附屬面積，勾選 **完整資料**，並指定樓層面積表的輸出位置。

已選取 polygon 時只處理選取範圍；沒有選取時處理整個圖層。可選多個 polygon，跨地段會查詢多組代碼。範圍多邊形在本機計算；查詢向來源網站傳送行政區、地段、建號等代碼。

### 事務所＋地段＋建號

| 範例 | 意義 |
| --- | --- |
| `EE` | 楠梓地政事務所代碼 |
| `0335` | 楠梓段一小段的地段代碼 |
| `00690000` | 建號 |
| `EE\|0335\|00690000` | 完整識別鍵 `building_key` |

單靠建號不能唯一識別建物。外掛利用 polygon 的位置查詢官方地段清單及界線，再取得對應事務所代碼；不是從 SHP 檔名猜測。無需自行輸入 `EE＋0335`。

### 已有建物定位點

使用 **2. 補齊建物資料與樓層面積**，指定地段欄 `section` 和建號欄 `build_no`。若有 `office` 欄會自動採用；沒有時可提供正確的備用事務所代碼。`EE` 只適用於楠梓地政事務所，不能套用於所有區域。透過外掛選單開啟時亦會採用已選取的點。

## 輸出內容

| 輸出 | 內容 |
| --- | --- |
| 一般定位點 | 建號、地段、完成日期、地址、樓層數、構造、面積、座標及事務所代碼 |
| 完整資料定位點 | 保留原始點與欄位，新增行政區、事務所名稱、地段、建物面積、樓層數、完成日期、主要用途及查詢狀態等 `moi_` 欄 |
| 樓層面積表 | 各層、屋頂突出物、陽台、騎樓等逐項列出；以 `building_key` 對應完整資料定位點 |

樓層面積表與定位點為一對多關係，不能把全部明細硬塞成同一筆面積或直接相加當作總面積。原始民國日期會保留，另提供有效的西元日期；缺漏或無效日期不會推算。

## 速度、取消及續跑

- 完整資料需要逐個建號查詢，每次請求至少間隔 1 秒。26,896 筆單計間隔已約 7.5 小時，另加網站回應時間，建議先以小範圍測試。
- 取消後用相同快取資料夾重跑，會重用成功取得的資料。要取得最新資料，請改用新空資料夾。
- 正在等待的網路請求不能即時取消，需要等回應或超時。網站回傳 HTTP 401、403 或 429 時會停止。
- 快取資料夾內的 `report.json`、`unlocated.json` 及 `detail_report.json` 提供執行結果、無法定位紀錄及明細查詢狀態；報告對應最近一次執行。
- 取消或失敗後的輸出可能不完整。重跑請使用新的輸出檔案，並檢查報告的 `finished` 及失敗紀錄。

## 資料來源與限制

- [高雄地籍圖資服務網](https://gisdawh.kcg.gov.tw/landeasy/)：地段界線、建號清單、定位座標與基本欄位。
- [內政部地籍圖資網路便民服務系統](https://easymap.moi.gov.tw/Z10Web/Normal)：事務所對應、建物基本資料與樓層／附屬面積。
- 本工具輸出是**建物登記定位點，不是建築外框**。同棟不同登記單位可能共用位置。
- 候選地段採範圍外擴 100 米，缺界線地段仍納入；最後按原範圍篩選定位點。來源錯置或缺少座標仍可能造成遺漏。
- 未登記、未提供或無法定位的建物不一定出現在結果內。來源沒有可核證的全量總數，不能保證「範圍內全部建物」完整無遺。
- 兩個來源的更新時間可能不同。網站格式或服務變更可能導致查詢失敗；快取亦不代表最新資料。

## 專案結構與打包

```text
kaohsiung_buildings_plugin/  QGIS 外掛原始碼與內建說明
scripts/build_plugin.py     產生可安裝 ZIP
tests/                    QGIS 離線整合測試與人工測試資料
dist/                     可安裝 ZIP
.github/workflows/          語法檢查及打包工作流程
```

使用 Python 3 執行：

```sh
python3 scripts/build_plugin.py
```

打包工具只收錄外掛所需檔案，不收錄查詢資料、快取及個人路徑。修改版本時更新 `metadata.txt`，再重新打包。GitHub Actions 會檢查 Python 語法及產生安裝包；不會連線下載建物資料，也不代表通過實際 QGIS 或資料正確性驗證。

### 測試

以能匯入 `qgis` 的 Python 環境執行：

```sh
QT_QPA_PLATFORM=offscreen python3 tests/test_qgis_integration.py
```

測試使用人工 HTML 與模擬資料來源，涵蓋外掛載入／卸載、選取範圍、位置保留、欄位解析、一對多關聯及錯誤紀錄。它不驗證即時網站可用性或官方資料完整性。一般系統 Python 未必可匯入 QGIS，請使用你的 QGIS Python 環境。

## 使用前請自行核對

**請使用者自行 check 資料同位置啱唔啱。** 使用前請抽查事務所、地段、建號、建物完成日期、面積及定位點，與來源網站和實際情況核對；亦要檢查缺漏、失敗紀錄及範圍是否正確。

本工具只協助整理查詢結果，**不保證資料正確、完整或最新，亦不代表已經人工或官方核證**。用於報告、規劃或其他正式用途前，應另行核實，並記錄資料來源及查詢日期。
