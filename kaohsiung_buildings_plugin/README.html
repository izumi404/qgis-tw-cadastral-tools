高雄建物資料助手 v2.0

只支援高雄市；QGIS 3.44–3.x，已以 3.44.7 測試。非政府官方外掛，無需額外 Python 套件。

安裝與使用

  1. QGIS → Plugins → Manage and Install Plugins → Install from ZIP，選 kaohsiung_buildings_plugin-2.0.0.zip。不用解壓，更新後可重啟 QGIS。
  2. 選取有正確座標系統的範圍 polygon；沒有選取時使用整個圖層。
  3. 開啟「1. 依選取範圍取得土地／建物資料」，選擇輸出類型。
  4. 指定快取資料夾及主要輸出，建議 GeoPackage。Polygon 若要保留獨立建號明細表，請指定該表的另一個輸出檔。
  5. 按 Run，開啟屬性表查看結果。

選擇輸出類型

模式輸出
Point：只有建物定位點範圍內建號、完成日期、地址、樓層、構造、面積、座標與事務所。不包含宗地或地價資料。
Polygon：土地＋建物資料與範圍相交的直接宗地向量、地號及面積、公告現值、公告地價、建號清單、完成日期摘要、逐筆建物 JSON 及一對多建號明細表。

預設 Point；兩種模式的輸入都是範圍 polygon。Polygon 預設裁切至範圍，取消裁切可保留完整宗地；裁切線不是原宗地界。不做 smooth。

土地及一地多建號

建號使用來源土地地段＋地號精確連結，不依定位點猜測。主圖層每幅地一筆，明細表每個建號一筆，以 parcel_key 連接。主圖層 buildings_json 亦保留逐筆基本資料；沒有指定明細表檔案時會建立暫存表。

ann_value 是公告現值，ann_price 是公告地價，單位為新臺幣元／平方公尺，並非整幅地總額。缺漏留空，真正的零值保留；value_year／price_year 因來源未提供而留空，不能用執行年份代入。

build_count／build_refs 為建號數量／清單；finish_min／finish_max 只代表最早／最遲有效完成日期，不能當作整幅地單一建築年份。建號數量不等於建築棟數，未找到建號不代表沒有建物。

額外建物明細

Point 模式可勾「完整資料」，另取主要用途、各層及附屬面積；每個建號一次查詢，數萬筆可能需數小時。Polygon 不適用此額外勾選。已有建物點圖層可使用「2. 補齊建物資料與樓層面積」，欄位指定 section、build_no 及 office；EE 只適用楠梓事務所。

報告、續跑與限制

  • Polygon 報告：快取資料夾內 polygon_report.json 及 polygon_unmatched_buildings.json。報告記錄缺口與重疊指標，不另產生診斷面圖層。
  • Point 報告：report.json、unlocated.json；額外明細：detail_report.json。
  • 每次最多 1,000 筆時遞迴拆查；網站 401、403、429 會停止。取消需等待正在進行的請求返回或超時。
  • 同快取可續跑；更新資料請用新空快取。快取不代表最新。取消或失敗後檢查 finished，重跑請用新輸出。
  • 來源每建號只提供一組地段／地號，不代表完整法定建物坐落地號清冊。位置在宗地外的建號仍依來源識別碼保留並標記。
  • 來源可能有缺口、重疊、缺幾何或座標；不會擅自補界、消除重疊或移位。定位點不是建築外框。

來源

高雄地籍圖資服務網；內政部便民系統；地價單位參考。

使用前請自行核對

請使用者自行 check 資料同位置啱唔啱。請核對事務所、地段、地號、建號、日期、面積、公告現值／地價、公告年度、位置及缺漏。工具不保證正確、完整或最新，並非人工或官方核證；正式使用前請另行核實並記錄來源及查詢日期。
