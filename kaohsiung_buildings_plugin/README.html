高雄建物資料助手 1.0

支援 QGIS 3.44，已以 3.44.7 測試。這是自訂外掛，非政府官方產品。無需安裝其他 Python 套件。

安裝

  1. QGIS → Plugins → Manage and Install Plugins → Install from ZIP。
  2. 選擇 kaohsiung_buildings_plugin-1.0.0.zip，安裝並啟用「高雄建物資料助手」。ZIP 不用先解壓。

選一個 polygon 就可以

  1. 載入 SHP 範圍圖層，用選取工具選擇所需 polygon；保持該圖層為目前圖層。
  2. Plugins → 高雄建物資料助手 →「1. 依選取範圍取得建物資料」。會自動採用已選取的 polygon；未選取圖徵時用整個圖層。
  3. 選一個快取資料夾及輸出 .gpkg，按 Run。自動找相交行政區、地段、事務所，再篩出界內定位點。
  4. 需要圖中全部欄位時勾「完整資料」，同時指定樓層面積表輸出。可選多個 polygon；跨段會自動查多組代碼。

範圍查詢只支援高雄市。範圍多邊形在本機計算，完整 SHP 不會上傳；查詢會向官方網站送出行政區、地段與建號等代碼。

已有定位點，不必重抓

選擇原本的建物定位點，開「2. 補齊建物資料與樓層面積」。地段欄選 section，建號欄選 build_no。 若圖層有 office 會自動採用；之前那份楠梓點圖層沒有此欄，可用備用值 EE。 如果是其他地政事務所，請選正確的事務所欄或輸入相應代碼，不能一律用 EE。

EE＋0335 是甚麼？

EE＝楠梓地政事務所；0335＝楠梓段一小段；00690000＝建號。 完整識別鍵為 EE|0335|00690000。單靠建號並非唯一識別。Polygon 是查詢範圍，可以對應多組事務所／地段。

輸出

  • 一般定位點：日期、地址、樓層、構造、面積、座標及事務所代碼。
  • 完整資料點：保留原始位置與欄位，新增行政區、事務所名稱、地段、建物面積、樓層數、完成日期、主要用途、查詢狀態、來源網址等 moi_ 欄。
  • 樓層面積表：一層、二層、屋頂突出物、陽台、騎樓等，每項一列。以 building_key 連接定位點；保留來源順序及面積原文。

完整資料需要逐個建號查一次。26,896筆單計每秒一次已約7.5小時，另加網站回應時間；建議先選小範圍／少量點測試。

續跑與資料限制

  • 取消後用相同快取資料夾重跑會重用成功結果；更新最新資料請改用新空資料夾。取消時輸出可能只有部分記錄，請核對報告 finished。
  • 快取資料夾內有範圍查詢 report.json、缺座標 unlocated.json、明細查詢 detail_report.json。這些報告對應最近一次執行。
  • 每次請求至少間隔1秒，網站回傳401/403/429會停止。無法即時取消正在等待的網路請求，最多等該請求超時。
  • 每個登記建號一筆。同棟單位可能重疊；定位點不是建築外框。日期缺漏或無效不會推算。
  • 候選地段採範圍外擴100米，缺界線地段仍納入；最後按原範圍精確篩點。遠離所屬地段界的錯置點仍可能遺漏。
  • 來源沒有官方可核證全量總數，不含未登記、未提供或無法定位的建物。點位精度依原網站。

來源與開發參考

高雄地籍圖資服務網； 內政部地籍圖資網路便民服務系統； QGIS 外掛結構文件。

使用前請自行核對

請使用者自行 check 資料同位置啱唔啱。請抽查事務所、地段、建號、建物完成日期、面積及定位點，與來源網站和實際情況核對，並檢查缺漏、失敗紀錄及範圍。

本工具不保證資料正確、完整或最新，亦不代表已經人工或官方核證。正式使用前應另行核實，並記錄資料來源及查詢日期。
